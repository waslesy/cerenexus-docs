# 第 1 章：API 是什么？有什么用？

## 1.1 API 是什么

API 就是 AI 公司开放出来的接口。你用第三方软件填上密钥，就能调用它家的大模型。不需要自己训练模型买显卡，按用了多少字付费。API Key 就是密钥，证明你有权限用。

> ⚠️ **安全警示：门禁卡丢了，刷的可不是你的脸**
>
> 申请到 API Key 后，有几件事一定要养成习惯：
>
> * **拿到立刻复制保存好。** 很多平台的 Key 只在生成的那一刻完整显示一次，窗口一关，下次进去看到的可能就是一串打了码的 `sk-xxx****xxx`，找不回原文，只能重新生成。
> * **绝对不要把 Key 分享给任何人**，哪怕是关系很好的朋友——这就跟把你家门禁卡复印一份送人没什么区别，对方刷的每一笔账，最后都算在你头上。
> * **自己用也建议设个用量上限。** 哪怕只有你一个人在用，手滑写出死循环调用、或者不小心把 Key 硬编码进了一直在跑的脚本，账单都可能在你没注意的时候悄悄爆炸。提前设个每日/每月限额，是给自己留的安全气囊。
> * **用 Agent（比如 Claude Code 之类能自己写代码、传文件的工具）时格外当心。** 最常见的翻车现场就是 Key 被不小心硬编码进代码里，然后连着项目一起传到了 GitHub 公开仓库——这种"裸奔的门禁卡"会被专门扫描 GitHub 的脚本盯上，几分钟内就可能被薅走刷爆，俗称"打野"。所以代码里的 Key 永远走环境变量或者 `.env` 文件，并且把 `.env` 写进 `.gitignore`。

## 1.2 API 和官方 App 的区别

| | 官方 App | API |
| :--- | :--- | :--- |
| **怎么用** | 打开网页/App 直接聊 | 配合第三方软件用 |
| **付费** | 按月订阅 | 按量付费，用多少扣多少 |
| **文件上传** | 有限制（免费版一天 3 个） | 基本没限制 |
| **内容审核** | 很严 | 宽松很多 |
| **功能** | App 说不能用的就不能用 | 模型支持的都能用 |

官方 App 是人家给你配好的，开箱即用。API 是自己折腾，但自由度高。

## 1.3 API 能用在哪些地方

API 不只是在酒馆（SillyTavern）玩角色扮演，还能用于：

*   **AI 聊天客户端**：Cherry Studio（电脑端）、RikkaHub（安卓端）、ChatBox 等，一个软件接多个模型
*   **翻译软件**：沉浸式翻译、OpenAI Translator
*   **编程辅助**：Cursor、Claude Code、GitHub Copilot，写代码 debug
*   **文档问答**：把自己的 PDF、Word 喂给 AI，对着文档提问
*   **邮件整理**：自动收发、总结、归类邮件
*   **自动化工作流**：搭配工具自动处理表格、发邮件、整理数据
*   **群聊机器人**：微信/QQ/Telegram 接上 API 当 AI 助手
*   **笔记软件**：Obsidian、Notion 里直接让 AI 润色总结

DeepSeek App 的专家模式用不了联网和上传文件，但 API 可以。ChatGPT 免费用户一天只能上传三个文件（包括图片），正常用肯定不够。有些软件上传图片有审核，不符合要求的传不了。用 API 基本没这些限制，具体用法看你个人需求。

## 1.4 API 其实更省钱，甚至能白嫖

订阅制看着省心，但大部分人月费交了用不完，额度纯浪费。API 按量计费，用多少花多少，不用不花钱。

而且很多渠道可以拿到免费额度：

*   **各大 AI 公司官方平台**，实名认证后就送 Token：
    *   智谱 AI：新用户送 2000 万 Token，永久额度
    *   硅基流动：注册送 2000 万 Token，永久有效
    *   火山引擎：每天约 200 万 Token
    *   阿里云百炼：每个模型 100 万 Token，覆盖 70+ 模型，总计超 7000 万
    *   腾讯混元：新用户 1 亿 Token 礼包
    *   百度千帆：实名认证后自动发放免费配额
    *   OpenAI：充值 $5 后开启数据共享，每天送高级模型 25 万 Token + 普通模型 250 万 Token，适合小规模测试
    *   Google Gemini：免费层永久可用，Gemini 2.5 Flash 每天 1440 次
    *   GitHub Models：有 GitHub 账号就能免费用 GPT-4.1、GPT-4o
*   **第三方中转平台**注册送赠金，邀请好友还能再拿
*   **官方时不时搞活动白送**，比如小米 MiMo 四五月份搞了百万亿 Token 激励计划，Kimi 世界杯期间搞了预测球队瓜分万亿 Token 的活动

综合下来，API 用起来反而比订阅便宜，甚至一分钱不花。

## 1.5 API 付费用户优先供给

API 是预付费的，算力资源优先给付费用户。免费网页版在高峰期经常弹"服务器繁忙请稍后再试"，但 API 用户基本不受影响。DeepSeek 算力紧张时直接限制免费用户的重新生成次数，付费的永远排在免费前面。
