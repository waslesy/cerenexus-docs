# CereNexus API 入门教程 · 引言

**在开始之前，我们需要达成几个共识**

写给"小白"的极度通俗教程，往往是最难写的。在正式翻开这本教程前，我有一些碎碎念，希望能帮大家建立正确的预期，少走弯路。

## 1. 别把时间浪费在"挑厨具"上，我们要学的是"做菜"

很多新手刚接触 AI，很容易陷入"工具迷恋"——一上来就去折腾像酒馆（SillyTavern）这样有着复杂界面的前端软件。

但说实话，这就相当于绕了远路。那些繁杂的 UI 界面和几十个按钮，只会让你觉得 AI 高深莫测。所以在这份教程里，我们绝对不从复杂的软件界面讲起，而是直接剥离外壳，去看 AI 最本源的样子。

记住：**如果你想真正了解 AI，就得把时间花在了解"AI 到底是什么"上，而不是在工具的按钮里迷路。**

## 2. 一个必要的取舍：严谨性让位于"说人话"

既然是零基础教程，我的第一原则就是"听得懂"。

为了达到这个目的，我会在教程里使用大量的、甚至可能有点离谱的**比喻**（比如切猪肉、数米粉、发考卷）。对于有一定基础的技术人员来说，这些比喻在某些专业细节上可能不够严谨。但这正是我深思熟虑后做出的取舍——只要能让你在第一时间建立起直观的认知，哪怕牺牲掉一点点学术上的严谨，也是绝对值得的。

大家可能会好奇：为什么在动手之前，我要在第 6、7 章硬核地去讲"上下文"和"注意力"？

因为哪怕你只是个普通的网页端用户，也一定遇到过"**聊着聊着 AI 就把设定全忘了**"，或者"发了一篇长文给它，它却只盯着最后两段胡说八道"的崩溃时刻。这不是因为你比较笨，而是因为 AI 记忆和处理文字的方式，本质上和人类完全不同，这种差异有它自己的物理极限。

## 4. 进村必看的"黑话字典"

在正式翻开教程前，你需要先掌握几个 AI 圈子里满天飞的"黑话"。它们本质上都很接地气：

* **八股：** 指的是模型**固定的说话格式和腔调**。当一个 AI 无论什么问题都喜欢列"一、二、三、四、总结"，或者总是带着死板的客套话时，我们就会说："这个模型的八股味太重了"。

* **蒸馏 (Distillation)：** AI 圈的"学霸抄作业"。模型的性格和说话风格不是一成不变的。开发者为了让小模型变聪明，会把顶级大模型做出来的满分试卷喂给小模型模仿。这会导致不同阵营的模型脾气互相传染。比如，你哪天可能会发现 DeepSeek 怎么带着一股 Gemini 的八股味？或者原本很有文采的 Claude 怎么突然变得像 GPT 那样像个机器人？这都是互相"蒸馏"的结果。

* **输出速度 (tok/s)：** 指的是 AI 每秒钟能往外蹦几个词（Token）。我们在第十二章会讲到这种"打字机"效果。为了让你有个直观的体感（以 1 个 Token 约等于 1.5 到 2 个汉字换算）：
    * 1~2 tok/s：人类日常在键盘上打字的速度，如果 AI 是这速度，看着会非常折磨。
    * 5 tok/s：人类正常的阅读速度，刚好能卡上你眼睛扫视、心里默读的节奏。
    * 15 tok/s：舒适的日常及格线，比你仔细读要快，适合"一目十行"地扫视。
    * 30 tok/s：目前大部分主流 API 的标准推理速度，文字刷屏很快，适合等它写完再回头细看。
    * 60+ tok/s：极速狂飙，人类的眼睛绝对跟不上了，这种速度通常用于让 AI 在后台自动处理海量文件或写代码。

* **模型参数量（B / T）：** 挑选模型时经常看到名字后面跟着 8B、72B 这样的后缀（B = 十亿，T = 万亿）。你可以把参数量理解为模型"知识连接网络"的稠密程度——就像人类大脑真正决定智力差距的不是神经元数量，而是突触连接的密度和复杂度。这里不按"聪明程度"分段位，而是按一个更实在的标准——**你能用什么硬件跑它**：

    | 量级 | 参数量 | 能跑在什么上 / 一句话定位 |
    |---|---|---|
    | 特化模型 | < 4B | 基本是为单一任务订制的小模型，比如 OCR、语音转写，不指望它陪你聊天 |
    | 消费级 | 8B ~ 30B | 消费级显卡（比如一张 24GB 显存的卡）能完整塞进去本地跑的上限 |
    | 本地重型 | 50B ~ 100B | 显卡基本带不动了，但用普通电脑的 CPU + 大内存硬啃，还能勉强跑出可用速度 |
    | 服务器级 | 100B+ | 个人设备彻底出局，得靠专门的多卡服务器机房才扛得住，我们日常在 API 里调用的顶级模型基本都在这个区间 |

    ⚠️ **但别记成"越大越好"！** 翻译润色这种轻活，8B 和 100B+ 的输出质量肉眼看不出差别，而小模型快如瀑布、账单约等于零。**杀鸡焉用牛刀，用最低成本搞定轻量工作，才是 API 世界的核心生存法则。**

    > 顺带一提：2026 年的开源圈，"服务器级"早就不是天花板了——像 DeepSeek V4、Kimi K2.6 这类总参数破万亿的开源模型已经陆续登场，体型直接对标顶级闭源模型。但这类巨兽用的是 MoE（混合专家）架构，每次回答只会"唤醒"其中一小部分参数干活，所以实际算力开销远没有"万亿"这个数字听起来那么吓人。

* **幻觉 (Hallucination)**： 模型遇到不会的问题时不会说"我不知道"，而是硬编一个听起来很像回事的答案。第五章会详细解释为什么会这样。
